# Security policy

## Supported versions

Security fixes are applied to the latest release line.

## Reporting a vulnerability

Please use GitHub's private security advisory feature for this repository. Do not open a public issue containing credentials, exploit steps, or sensitive repository data.

Include:

- affected version and operating system
- the exact command or workflow involved
- impact and realistic attack prerequisites
- a minimal reproduction when safe
- suggested mitigation, if known

The `security-audit` skill is a workflow aid, not a substitute for professional security review, deterministic scanners, access controls, or incident response.
