# Code of conduct

We want this project to be useful, respectful, and technically rigorous.

Contributors must:

- Treat people with respect, including when disagreeing about design choices.
- Focus criticism on code, evidence, and outcomes rather than individuals.
- Avoid harassment, discrimination, threats, or publication of private information.
- Disclose conflicts of interest when recommending tools or vendors.
- Report security issues privately instead of publishing exploitable details.

Project maintainers may edit or remove contributions and restrict participation when behavior undermines a safe and productive community.
