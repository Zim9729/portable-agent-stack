# Third-party integrations

Portable Agent Stack does not vendor the projects below. The CLI can optionally install or configure them from their official distribution channels. Their licenses apply independently.

| Project | Role | Upstream license |
|---|---|---|
| [Trellis](https://github.com/mindfold-ai/Trellis) | Task workflow, specs, and project memory | AGPL-3.0 |
| [CodeGraph](https://github.com/colbymchenry/codegraph) | Code graph, call paths, and impact analysis | MIT |
| [Headroom](https://github.com/headroomlabs-ai/headroom) | Context and tool-output compression | Apache-2.0 |
| [Matt Pocock skills](https://github.com/mattpocock/skills) | Engineering methods and reusable skills | MIT |
| [gstack](https://github.com/garrytan/gstack) | Optional deep QA, security, and documentation backend | Check the upstream repository before use |

This repository's MIT license covers only the original CLI, templates, documentation, and supplemental skills shipped here. It does not relicense third-party software.

Trellis is AGPL-3.0. Organizations should review the upstream license and their deployment model before adopting it. This document is not legal advice.
