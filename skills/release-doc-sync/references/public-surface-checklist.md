# Public surface checklist

- exported APIs, schemas, endpoints, and events
- CLI commands, flags, output, exit codes, and examples
- configuration keys, defaults, environment variables, and secrets
- installation, upgrade, migration, and rollback steps
- authentication, permissions, and security behavior
- user-visible workflows, limitations, and error messages
- operational commands, alerts, dashboards, and runbooks
- deprecated, renamed, or removed behavior

## Documentation coverage

Classify applicable documents using Diataxis concepts:

- tutorial: learning-oriented walkthrough
- how-to: goal-oriented procedure
- reference: precise facts and interfaces
- explanation: concepts, rationale, and architecture

Not every change needs all four. Record intentional gaps and ownership.
